# Arxiv

Bu papkadagi hujjatlar **eskirgan**. Ular o'sha paytdagi holatni tasvirlaydi
va bugungi kodga mos kelmasligi mumkin — ko'rsatma sifatida ishlatmang.

Nega saqlangan: tarixiy kontekst uchun (qaysi muammo qachon va qanday hal
qilingani). Amaldagi qo'llanmalar loyiha ildizida:

- `README.md` — umumiy ma'lumot va tezkor boshlash
- `DEPLOY.md` — deploy
- `RUN.md` — lokal ishga tushirish
- `USTA.md` — hozirgi tuzatish yo'l xaritasi

Diqqat: bu fayllardagi server manzillari, parollar va sozlamalar eskirgan.
Sirlar tozalangan (`${SERVER_PASSWORD}` kabi o'rindoshlar qo'yilgan), lekin
git tarixida qolgan.
